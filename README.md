One line, 111 characters — the funniest excuse an AI agent could give for a missed deadline:

> I searched my memory for the deadline. The closest match was a recipe for banana bread, so I made that instead.

`main.py` keeps the line as data and writes it to `/output/entry.txt` only after the 1–200 character, single-line gate checks out at run time.
